# Jira Issue Tracking Skill

This skill allows you to interact with Jira backlogs, tickets, and user stories using the `jira` command.

## Usage
The `jira` command is available in the system PATH.

- **List issues in current project**:
  ```bash
  jira issue list
  ```
- **Create an issue**:
  ```bash
  jira issue create
  ```
- **View an issue**:
  ```bash
  jira issue view <issue-id>
  ```
