# OpenAPI Linting Skill

This skill allows you to check and lint API specifications (like OpenAPI, Swagger, AsyncAPI) using the `spectral` command.

## Usage
The `spectral` command is available in the system PATH.

- **Lint an API spec file**:
  ```bash
  spectral lint openapi.yaml
  ```
