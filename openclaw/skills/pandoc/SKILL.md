# Pandoc Document Conversion Skill

This skill allows you to compile specifications, functional design documents, and user stories between format representations.

## Usage
The `pandoc` command is available in the system PATH.

- **Convert Markdown to Word (DOCX)**:
  ```bash
  pandoc input.md -o output.docx
  ```
- **Convert Markdown to HTML**:
  ```bash
  pandoc input.md -o output.html
  ```
