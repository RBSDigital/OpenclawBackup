# Privacy Boundaries

This vault is shared agent memory. Treat it as visible across the agent team.

## Allowed

- Sanitized procedures.
- Non-secret system conventions.
- Public source summaries with citations or links.
- Cross-agent routing decisions.
- Durable lessons that improve future work.
- Project facts Vincent wants available to the agent team.

## Not Allowed

- Secrets, credentials, API keys, private keys, OAuth tokens, cookies, recovery codes, or passwords.
- Raw user transcripts or private chats.
- Personal information that does not need cross-agent sharing.
- Full contents of `MEMORY.md`, `USER.md`, `SOUL.md`, or private workspace notes from any agent.
- Sensitive security findings that lack an explicit sharing decision.

## Sensitive Facts

If a fact helps one agent but should not be shared broadly, keep it in that agent's private workspace memory instead of this vault.
