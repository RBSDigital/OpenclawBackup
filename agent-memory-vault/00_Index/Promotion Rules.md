# Promotion Rules

Use this flow to turn short-lived context into durable recall.

## Promote To Workspace Daily Memory

Use `memory/YYYY-MM-DD.md` for:

- What happened today.
- Task outcomes.
- Temporary context.
- Raw observations that may or may not matter later.

## Promote To Private `MEMORY.md`

Use the agent's private `MEMORY.md` for:

- Private user preferences.
- Agent identity and long-term behavioral lessons.
- Sensitive but useful context that should not be shared in group channels.

## Promote To This Vault

Use the Agent Memory Vault for:

- Reusable procedures.
- Cross-agent decisions.
- Sanitized project context.
- Source-backed research summaries.
- Routing and ownership rules.
- Toolchain facts that multiple agents need.

## Required Metadata

Every durable note should include:

- `owner`
- `created`
- `last_verified`
- `status`
- `confidence`
- `source`

Use `unknown` when necessary, then update later.
