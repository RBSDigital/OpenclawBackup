# Continuous Improvement - ITC

This folder contains a practical research and remediation pack for the ITC continuous improvement feedback themes.

## Documents

- `01-feedback-point-research-and-remediation-plan.md` - research notes, remediation ideas, artefacts, owners, and measurement approach for each feedback point.
- `02-delivery-artefact-templates.md` - reusable templates for RAID, action tracking, decision logging, dependencies, meeting minutes, sprint review outputs, and status reporting.
- `03-improvement-measurement-scorecard.md` - suggested KPIs, leading indicators, reporting cadence, and governance model.

## Source Feedback Themes

- Deployment troubleshooting difficulty
- System / architecture documentation gaps
- Technical debt governance
- Collaboration tool usage, including ADO and SharePoint
- Due date and dependency tracking
- Collaboration tool usage for delivery artefacts
- Sprint retrospectives and sprint reviews
- Communication clarity
- Stakeholder collaboration concerns
- Responsiveness concerns
- Meeting discipline

## Suggested Operating Rhythm

- Weekly: review RAID, action tracker, dependency tracker, technical debt backlog, and overdue items.
- Fortnightly: review sprint retrospective actions and sprint review evidence.
- Monthly: review the improvement scorecard and agree priority changes.
- Quarterly: refresh architecture documentation, stakeholder map, delivery roadmap, and measurable improvement targets.
