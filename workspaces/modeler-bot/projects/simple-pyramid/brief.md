# Simple Pyramid Brief

- Project: simple-pyramid
- Version: version_0.1.0
- Request: create a pyramid using Blender that is ready to print on a 3D printer.
- Object/use case: decorative solid square pyramid.
- Printer target: Elegoo Neptune 3/4.
- Build volume: 225 x 225 x 265 mm.
- Material assumed for notes: PLA.
- Deliverables: Blender source file and STL export for review.

## Dimensions

- Base: 60 mm x 60 mm square.
- Height: 60 mm.
- Bottom: flat on build plate.
- Part count: one.

## Print Intent

The pyramid is modeled as a closed solid with a flat square base and four triangular sides. It is intended as a general decorative print, not a load-bearing or safety-sensitive part.
