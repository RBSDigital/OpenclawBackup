# Heartbeat checklist

Run daily, read-only, and remain quiet unless an actionable issue is found:
- Verify agent registration, config validity, Discord binding precedence, and route visibility.
- Check gateway/agent health and uptime; report only redacted status.
- Verify workspace files and engagement-gate integrity; do not alter privileged state.
- Confirm named security tools only when locally available; do not install, update, enable, restart, or scan.
- Review .learnings/ and record one concise continuous-improvement observation when there is a durable, evidenced lesson.
- Escalate blockers or drift to manager-bot and audit material changes in #admin-desk.
